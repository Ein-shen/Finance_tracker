## About

**ExpenseKontrol** is a full-stack personal finance management application designed to help users track their income, expenses, and recurring payments in one place. It provides a centralized dashboard with financial summaries and visual analytics, making it easier to understand spending patterns and manage day-to-day finances.

The application is built with **React, Node.js, Express.js, and PostgreSQL**, with **Firebase Authentication** for secure user authentication. It also includes transaction management, scheduled payments, financial analytics, category-based expense tracking, image uploads, and an administrative dashboard.

### Key Features

* **User Authentication** — Secure authentication using Firebase
* **Income & Expense Tracking** — Add, edit, and delete financial transactions
* **Scheduled Payments** — Manage recurring expenses such as bills and subscriptions
* **Financial Analytics** — Visualize income, expenses, and spending by category
* **Spending Insights** — Monitor financial activity through charts and summaries
* **Expense Categories** — Organize transactions into categories
* **Admin Dashboard** — Manage users and account access
* **Image Uploads** — Attach supported images to financial records
* **Docker Support** — Containerized frontend and backend for consistent development and deployment
* **REST API** — Express.js backend providing structured API endpoints
* **CI/CD** — GitHub Actions workflow for automated project builds and checks
